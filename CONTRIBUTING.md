# Contributing to Voice Receptionist

Thank you for your interest in contributing! This project is open source and welcomes pull requests.

## Development Setup

1. Fork and clone the repo
2. Follow the Quick Start in [README.md](README.md)
3. Run the seed script so you have demo data to work with

## Code Style

- **Backend:** Follow PEP 8. Type-annotate all function signatures. Keep docstrings concise.
- **Frontend:** ESLint + Prettier (run `npm run lint` before committing).
- **Commits:** Use conventional commit messages (`feat:`, `fix:`, `docs:`, `refactor:`)

## Pull Request Process

1. Branch off `main`
2. Write or update tests for your change
3. Ensure `npm run build` and backend imports pass cleanly
4. Open a PR with a clear description of what changed and why

## Reporting Bugs

Open a GitHub issue with:
- Steps to reproduce
- Expected vs actual behaviour
- Your OS and Python/Node version
